experimented with a few more values under this configuration, such as k=30 and k=50. As expected with increased k, image accuracy goes down but sentiment accuracy increases. 
In the case of image accuracy, the best accuracy appears under k=1, but this suggests that larger neighbourhoods introduce competing class labels that negatively influence uniform voting.

we also found that tie-breaking contributed to the decline in accuracy, particularly when increasing k from 1 to 3. 
Of the 601 predictions that changed from correct to incorrect, 495 involved three neighbours belonging to three different classes, resulting in a three-way tie. 
In our implementation, ties are resolved using np.argmax(), which selects the class with the smallest numerical label
because it returns the first index of the max value, so for the 3 way tie, it most likely returned the index with the smallest index, regardless of which neighbour is closest. As a result, even when the nearest neighbour belongs to the correct class, the prediction can become incorrect simply because another class has a smaller numerical label. 
This suggests that both the introduction of competing class labels and our tie-breaking strategy contribute to the decrease in validation accuracy as k increases.
